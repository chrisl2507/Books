# Books

A catalogue of the books on the shelves at home — 200 titles, each with its
cover, author, publisher, page count, ISBN and a short description.

Published with GitHub Pages at <https://chrisl2507.github.io/Books/>

## About the page

`index.html` is a single self-contained file. Cover images are embedded
directly as base64 JPEG data, so the page has no external image
dependencies and works offline once loaded — which is why the file is
around 2.4 MB. The only external requests are for the web fonts.

The catalogue supports free-text search across titles, authors and
descriptions, and can be sorted from the controls at the top. Selecting a
book opens its full details.
